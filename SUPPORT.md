# Getting help

- **Questions and ideas:** start a discussion in the [community repository](https://github.com/OpenWave-India/community/discussions), or in the project's own Discussions tab if it has one.
- **Bugs and feature requests:** open an issue in the repository the problem is in, using the issue forms.
- **Security problems:** don't open a public issue; follow the [security policy](SECURITY.md).

Maintainers are volunteers, so please allow a few days for a reply.
