
OpenWave India
India's open AI ecosystem, built together.

OpenWave India builds open-source developer tools for AI, with a focus on software that runs locally, is tested properly, and is easy to contribute to.

Projects
Project	What it does
modeldiff	Regression testing for local AI. Compare model versions, quantizations, prompts and runtimes, and see exactly what broke. Runs offline, no API keys.
veriflow	A verification skill for Claude Code that checks AI-generated code with tests, security scanning, API contract checks and browser workflows.
community	Discover projects, propose ideas, and find people to build with.
Contribute
New contributors are welcome, and you don't need prior open-source experience.

Pick an issue labelled good first issue.
Comment on the issue to say you're working on it.
Read the project's CONTRIBUTING.md, open a pull request, and a maintainer will review it.
Everyone whose pull request is merged is credited in the project's README and release notes.

Get in touch
Ideas, questions and project proposals go to community discussions. Please follow each project's code of conduct.
